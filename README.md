# Tkinter Shockwave Director Extraction GUI For macOS + Wine

This is a GUI I made in Tkinter for my experiments with Macromedia Shockwave programs. it requires macOS and Wine to work properly. It was originally meant for personal use. I spent 3 days working on it. No AI was used

I couldn't really get a good chunk of the features to work properly and I kinda felt like I should go. So I'm just sharing it here so someone else can use it or maybe even help me fix it.
